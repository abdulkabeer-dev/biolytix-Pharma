# Products Data Upload Directory

Place your Excel file (`.xlsx`, `.xls`) or CSV (`.csv`) containing the Biolytix product catalogue into this folder:

```
c:\Users\aser\Downloads\Biolytix\products_data\
```

### Supported Columns (flexible naming):
- **Division** / Category (e.g. *Anti-Infectives, Analgesics, Cardiac Care, Derma, Gastro, Respiratory, Multivitamins, Ophthalmic*)
- **Product Name** / Brand Name (e.g. *BIOLOX-CV 625, PANTOBIOL-DSR*)
- **Composition** / Active Ingredients (e.g. *Amoxycillin 500mg + Clavulanic Acid 125mg*)
- **Dosage Form** (e.g. *Tablet, Capsule, Syrup, Gel, Suspension, Drops, Injection, Ointment*)
- **Packaging** / Pack Size (e.g. *10x10 Alu-Alu, 100ml, 30g Tube*)
- **Indication** / Therapeutic Use (e.g. *Bacterial infections, Acid reflux, Pain relief*)

Once uploaded, let me know and I will automatically parse the entire file and update the live website catalogue!
